title: Past simple of common irregular verbs
kind: grammar
level: A2

The past simple of regular verbs takes **-ed**. The fifty most common English verbs are mostly
irregular, so learners meet them constantly in speech.

High-frequency set worth hearing often:

- go -> went, buy -> bought, eat -> ate, see -> saw, take -> took
- come -> came, get -> got, make -> made, have -> had, do -> did
- say -> said, tell -> told, think -> thought, know -> knew, give -> gave
- write -> wrote, read (unchanged spelling, said "red"), run -> ran, drink -> drank
- begin -> began, break -> broke, choose -> chose, drive -> drove, fall -> fell
- feel -> felt, find -> found, fly -> flew, forget -> forgot, hear -> heard
- keep -> kept, leave -> left, lose -> lost, meet -> met, pay -> paid
- put -> put, read -> read, ride -> rode, ring -> rang, send -> sent
- sing -> sang, sit -> sat, sleep -> slept, speak -> spoke, spend -> spent
- stand -> stood, swim -> swam, teach -> taught, wear -> wore, win -> won

Learners with many first languages drop the past tense marker in fast speech:

- "Yesterday I go" -> "Yesterday I went"
- "I buy some milk" -> "I bought some milk"
- "She say she is tired" -> "She said she was tired"

The negative and question forms use the base verb after *did*: "I didn't go", "Did you buy
it?" - never "I didn't went".

If a learner says "I have went", treat it as a natural over-correction of *have + past
participle* and recast it silently: "I've gone" or "I went".
